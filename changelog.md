## 3.2.0 - 2026-03-31
* The SDK now supports additional appointment and payor providers. New enum values added for "sonora_quest" in appointment providers and "apero", "pverify" in payor code external providers. Some unused timeseries and index enum values have been updated.
* New optional parameters are now available for enhanced lab test functionality:
* `labSlug` parameter in `getMarkers()` for filtering markers by lab slug
* `orderTransactionId` parameter in `getOrders()` for filtering orders by transaction ID
* `allowStale` parameter in `getPscAppointmentAvailability()` to allow cached availability data
* `clinicalNotes` parameter in order creation for additional clinical information
* The SDK now includes three new client modules: `CompendiumClient`, `LabAccountClient`, and `OrderTransactionClient` for expanded API access. The insulin injection sample data model has been enhanced with additional fields for delivery mode, delivery form, and bolus purpose information. New lab providers and manual providers have been added for broader integration support.
* New compendium, lab account, and order transaction management capabilities are now available. The SDK includes CompendiumClient for lab test search and conversion between labs, LabAccountClient for managing lab partnerships, and OrderTransactionClient for tracking order transactions and retrieving results. Enhanced appointment booking now supports notes and additional providers including Sonora Quest.
* The SDK now supports comprehensive lab testing workflows including order transactions, lab account management, and report parsing webhooks. New insulin injection timeseries data types are available for diabetes management applications. Additional provider support includes Samsung Health and Tandem Source integrations.
* New lab compendium search functionality available through `CompendiumClient` with `searchCompendium()` and `convertCompendium()` methods for discovering and converting lab tests across providers. Insulin injection data now includes delivery mode, form, and bolus purpose tracking. Order management enhanced with transaction tracking, clinical notes support, and improved appointment scheduling with notes.
* The SDK now supports order transactions for tracking related orders together, with new transaction status monitoring and order origin classification. Enhanced order events include detailed status information, and lab account management capabilities are now available. Additional provider support includes Tandem Source and Samsung Health integrations. Sleep data now includes recovery readiness scoring, and patient addresses support access notes.
* The SDK now supports lab test compendium search with `SearchCompendiumResponse` and related types, enabling search across canonical and per-lab test databases. New order transaction tracking capabilities are available through `OrderTransaction` and related types. Insulin injection data now includes enhanced metadata with bolus purpose, delivery form, and delivery mode information. Sleep data expressions now support derived readiness scores, and address types include optional access notes for delivery instructions.
