## 4.0.0 - 2026-03-27
* The SDK now supports Sonora Quest as a lab provider option in appointment scheduling and lab ordering. New payor code providers (apero, pverify) are available for insurance verification. A new derived_readiness index type has been added for data queries. Note that the insulin_injection timeseries type has been removed - existing code referencing this type will need to be updated.
* The `parserCreateJob` method now accepts an array of files instead of a single file. Update your code to pass files as an array: `client.labReport.parserCreateJob([file], request)` instead of `client.labReport.parserCreateJob(file, request)`.
* Added new optional parameters: `orderTransactionId` for order filtering, `clinicalNotes` field for order creation, and `allowStale` option for PSC appointment availability requests. Enhanced method documentation for better clarity.
* Added support for iOS and Android SDK version tracking in manual connection requests through new optional header fields.
* The SDK now includes three new client resources: CompendiumClient, LabAccountClient, and OrderTransactionClient, providing access to additional Vital API capabilities. The insulin injection data model has been expanded with new optional fields for tracking delivery mode, delivery form, and bolus purpose, enabling more detailed diabetes management insights.
* The SDK now includes three new client modules for enhanced lab testing capabilities:
* **CompendiumClient**: Search and convert lab test data with `search()` and `convert()` methods
* **LabAccountClient**: Manage team lab accounts with `getTeamLabAccounts()` method
* **OrderTransactionClient**: Retrieve transaction details and lab results with `getTransaction()`, `getTransactionResult()`, and `getTransactionResultPdf()` methods
* Additional enhancements include new optional fields for lab account management and appointment scheduling, plus expanded filtering options for lab test queries.
* The SDK now supports insulin injection tracking with detailed delivery information including modes, forms, and bolus purposes. Lab account management capabilities are available for handling delegated testing flows. New compendium search functionality enables test conversion between different lab providers. Enhanced address handling includes access notes for delivery instructions, and expanded order transaction support provides better status tracking throughout the testing process.
* New lab test compendium search and conversion endpoints enable discovery and mapping of medical tests across different lab providers. Enhanced insulin injection tracking now includes delivery modes (basal/bolus), delivery forms (standard/extended), and bolus purposes (meal/correction/mixed/unknown). Lab account management capabilities added with comprehensive account status tracking and billing configuration support. Order transaction management and enhanced appointment booking with clinical notes and confirmation options are now available.
* The SDK now supports lab account management, order transactions, and insulin injection data tracking. New types include ClientFacingOrderTransaction for grouping related orders, lab account management capabilities, and support for insulin pump data sources. Additional provider support has been added for Tandem and Samsung Health.
* New serialization types added for compendium search functionality, enhanced address handling with US state validation, and expanded support for insulin injection data and lab account management.
