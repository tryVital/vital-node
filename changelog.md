## 4.0.0 - 2026-03-20
* The SDK now supports SonoraQuest as a new lab provider option for appointments and lab services. A new derived_readiness index is available for data queries, and additional external providers (apero and pverify) are supported for payor code operations.
* The `parserCreateJob` method now accepts multiple files for batch processing. The method signature has changed from `parserCreateJob(file, request)` to `parserCreateJob(files, request)` where `files` is an array. To migrate existing code, wrap your single file in an array: `parserCreateJob([file], request)`.
* The LabTestsClient now supports additional optional parameters: `labSlug` in `getMarkers()`, `orderTransactionId` in `getOrders()`, `allowStale` in `getPscAppointmentAvailability()`, and `clinicalNotes` in `createOrder()`. These parameters provide enhanced filtering and configuration options for lab test operations.
* Added support for iOS and Android SDK version tracking in manual connection endpoints.
* This release contains breaking changes to several type definitions. The `ParsingJob` interface no longer includes the `jobId` property. The `ResultMetadata` interface now has optional fields for `patientFirstName`, `patientLastName`, `dob`, and `labName`. The `UserInfo.address` property type has changed from `Address` to `UserAddress`. New client endpoints are available: `CompendiumClient`, `LabAccountClient`, and `OrderTransactionClient` for enhanced lab processing and compendium management capabilities.
* The SDK now includes three new client modules: `CompendiumClient` for lab test search and conversion operations, `LabAccountClient` for managing team lab accounts, and `OrderTransactionClient` for retrieving order transactions and results. Additional optional fields have been added to various request types to support enhanced functionality.
* The SDK now supports comprehensive lab test compendium search and conversion, order transaction management, lab report parsing job tracking, and expanded provider coverage including Sonora Quest, Samsung Health, and Tandem Source. Enhanced appointment booking with async confirmation options and added support for delivery access notes across address types.
* The SDK now supports a new compendium resource for lab test search and provider ID conversion. New optional parameters have been added to lab test creation, order creation, and appointment booking for enhanced functionality including clinical notes, lab account selection, and appointment confirmation settings.
* The SDK now supports lab account management with new types for tracking account status, order transactions, and provider mappings. Added biomarker compendium search capabilities with canonical and crosswalk search modes. Extended address models to include access notes for delivery instructions. Added support for Tandem Source and Samsung Health providers.
