## 4.0.0 - 2026-03-19
* The SDK now supports Sonora Quest as a new appointment provider. The AppointmentPscLabs type has been expanded from a single value to include both "quest" and "sonora_quest" options. Additional enum values have been added for readiness data indexing and payor code providers.
* The lab report parser job creation method now accepts an array of files instead of a single file, enabling batch processing of multiple lab reports in a single request. Update your code to pass an array of files: `parserCreateJob([file1, file2], {...})` instead of `parserCreateJob(file, {...})`.
* New optional parameters added: `orderTransactionId` for filtering orders and `allowStale` for PSC appointment availability queries to allow cached data.
* New API clients added for compendium, lab account, and order transaction operations. The ResultMetadata type has been updated to make patient information fields optional, and new provider types are now supported including Samsung Health and Tandem Source.
* The SDK now supports three new client modules: CompendiumClient for searching and converting lab test information, LabAccountClient for managing team lab accounts, and OrderTransactionClient for tracking lab test transactions and retrieving results. Additional enhancements include new optional parameters for lab test creation and improved filtering options across existing endpoints.
* The SDK now supports order transaction tracking to group related lab orders, comprehensive lab test search and conversion through new compendium endpoints, and expanded appointment booking with notes and async confirmation options. Additional support includes Sonora Quest lab integration and derived readiness data in analytics queries.
* The SDK now supports compendium search and conversion operations through new request types and response structures. Enhanced appointment booking with optional notes fields, and added comprehensive order transaction tracking capabilities.
* New compendium search capabilities allow searching and cross-referencing lab markers across different providers. Added support for Tandem Source and Samsung Health providers. Enhanced lab order system with transaction tracking and expanded address models with access notes.
