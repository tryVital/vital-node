## 4.0.0 - 2026-03-30
* The SDK has removed several deprecated optional parameters and enum values while adding support for new lab providers and data types. The `teamId` parameter has been removed from bulk connection operations (`BulkExportConnectionsBody`, `BulkImportConnectionsBody`, `BulkPauseConnectionsBody`, `BulkTriggerHistoricalPullBody`) as it was previously unused. New lab provider "sonora_quest" is now supported across appointment and lab-related operations. Additional enum values have been added for readiness data ("derived_readiness") and payor code providers ("apero", "pverify").
* The SDK now supports additional filtering and configuration options: `orderTransactionId` parameter for filtering orders, `allowStale` parameter for PSC appointment availability to enable cached data retrieval, `labSlug` parameter for marker filtering, and `clinicalNotes` field for order creation. All new parameters are optional and backward compatible.
* The SDK now includes new optional fields for insulin injection samples (deliveryMode, deliveryForm, bolusPurpose), additional client methods (compendium, labAccount, orderTransaction), and enhanced parsing job functionality with failure reason tracking. Several new provider types and order statuses are now supported.
* New compendium endpoints for searching and converting lab tests between different labs. New lab account management client for retrieving team lab accounts. Enhanced lab test creation and order management with additional filtering and configuration options.
* The SDK now supports insulin injection tracking with detailed delivery modes, bolus purposes, and delivery forms. New lab report parsing job webhook events are available for monitoring document processing status. Order transaction management capabilities have been added with status tracking across multiple related orders. Samsung Health and Tandem Source are now supported as data providers, and Sonora Quest lab integration is available with comprehensive lab account management features.
* The SDK now supports compendium search functionality for lab test discovery and conversion. Enhanced insulin injection data includes delivery mode, delivery form, and bolus purpose information. Added support for appointment notes, clinical notes, lab account management, and order transaction tracking.
* The SDK now supports lab account management, order transaction tracking, and insulin injection data queries. New functionality includes lab account status monitoring, order transaction grouping with status tracking, and insulin injection timeseries expressions for advanced health data queries. Additional enhancements include clinical notes on orders, patient address access notes, and support for new health data providers (Tandem Source and Samsung Health).
* The SDK now supports access notes on address types and includes new lab compendium search functionality. New search capabilities allow querying lab tests with canonical and crosswalk modes, plus enhanced metadata for lab orders including US state validation and result gender classification.
