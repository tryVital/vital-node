## 3.2.0 - 2026-03-30
* The SDK now supports Sonora Quest as a lab provider option. Several optional `teamId` parameters have been removed from link operation request interfaces as they are no longer needed.
* New optional parameters available for lab test operations: `labSlug` for filtering markers, `orderTransactionId` for filtering orders, `allowStale` for appointment availability caching, and `clinicalNotes` for order creation.
* New client interfaces are now available: `CompendiumClient`, `LabAccountClient`, and `OrderTransactionClient` accessible through the main VitalClient. Insulin injection samples now include additional tracking fields for delivery mode, form, and bolus purpose to provide more detailed health data insights.
* New Compendium, LabAccount, and OrderTransaction clients provide comprehensive lab testing management capabilities. The SDK now supports lab test search and conversion operations, team lab account management, and transaction tracking with result retrieval. Enhanced lab test creation includes new lab account and lab slug options, while appointment booking now supports asynchronous confirmation workflows.
* The SDK now supports insulin injection data with delivery modes (basal/bolus), delivery forms (standard/extended), and bolus purposes (meal/correction/mixed). Insulin pump has been added as a new source type for device, ECG, menstrual cycle, and sleep data. Enhanced appointment management includes transaction tracking, lab account configurations, and expanded order processing with new status details. Added access notes to address types and support for Samsung Health provider.
* The SDK now supports compendium search functionality for lab tests, with new methods for searching and converting lab test data. Lab account management capabilities have been added, allowing teams to manage lab accounts with status tracking and delegated flows. Insulin injection data now includes additional fields for delivery mode, delivery form, and bolus purpose. Appointment booking has been enhanced with support for appointment notes and asynchronous confirmation options.
* The SDK now supports order transaction management with new transaction status tracking and order relationship capabilities. Added insulin injection timeseries expressions for querying insulin data. Enhanced order and patient models include additional optional fields like clinical notes and access notes.
* The SDK now supports new enum types for search modes, gender metadata, and US states. Address handling has been enhanced with a new UserAddress type and optional access notes on existing address types. New response types are available for compendium search, lab accounts, and order transactions.
