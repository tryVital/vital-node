## 4.0.0 - 2026-03-27
* The SDK now supports additional lab providers and external payor providers. New enum values include SonoraQuest for appointment PSC labs and sonora_quest for appointment providers, plus apero and pverify for payor code external providers. The derived_readiness index is now available for data queries.
* The lab report parser now accepts multiple files in a single request. The `parserCreateJob` method parameter has changed from a single `Uploadable` to an array of `Uploadable[]`. Existing code passing a single file must be wrapped in an array: `parserCreateJob([file], request)`.
* The SDK now supports additional optional parameters for lab test operations: `orderTransactionId` for filtering orders, `labSlug` for marker queries, `allowStale` for cached appointment availability, and `clinicalNotes` for order creation. All existing functionality remains unchanged.
* The SDK now includes three new client resources: `compendium`, `labAccount`, and `orderTransaction` accessible from the main VitalClient. Enhanced insulin injection sample types with new optional fields for delivery mode, delivery form, and bolus purpose. Added support for new health providers including Samsung Health and Tandem Source.
* The SDK now includes three new client modules: `CompendiumClient` for searching and converting lab test data, `LabAccountClient` for managing lab accounts, and `OrderTransactionClient` for tracking order transactions and retrieving results. Additional optional parameters have been added to existing lab test operations for enhanced functionality.
* The SDK now supports insulin injection data tracking with detailed delivery information including modes, forms, and bolus purposes. Order transaction functionality allows grouping and tracking related orders together. Lab account management features enable configuration of delegated testing flows. Address fields now include access notes for delivery instructions, and appointment booking supports asynchronous confirmation with customizable timeout settings.
* The SDK now supports compendium search functionality for discovering lab tests, with new `searchCompendium()` and `convertCompendium()` methods available on the CompendiumClient. Insulin injection data now includes additional fields for delivery mode, form, and bolus purpose. Lab testing features have been extended with support for appointment notes, clinical notes in order creation, and lab account management capabilities.
* The SDK now supports lab account management with team lab accounts retrieval and status tracking. Added order transaction functionality for grouping and monitoring related orders. New insulin injection timeseries support enables comprehensive diabetes management data collection. Enhanced compendium search capabilities allow lab test conversion between providers. Added support for Tandem Source and Samsung Health providers. Order data now includes clinical notes, origin tracking, and transaction associations.
* The SDK now supports additional serialization types for lab compendium search, comprehensive US address handling, insulin injection time series data, and derived readiness metrics. New enum types include US states and search modes for enhanced data modeling capabilities.
