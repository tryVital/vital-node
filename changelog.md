## 4.0.0 - 2026-03-13
* New enum values added for lab providers and external integrations. AppointmentPscLabs now supports both "quest" and "sonora_quest" values. PayorCodeExternalProvider includes new "apero" and "pverify" options. IndexColumnExprIndex adds "derived_readiness" for readiness data queries.
* The `parserCreateJob()` method now accepts an array of files instead of a single file. Replace `parserCreateJob(file, options)` with `parserCreateJob([file], options)` to migrate existing code.
* New optional parameters available: `orderTransactionId` for filtering orders, `labSlug` for filtering markers, `allowStale` for appointment availability caching, and `clinicalNotes` for order creation. Updated method documentation with clearer descriptions.
* Breaking changes to ParsingJob and ResultMetadata interfaces. The ParsingJob.jobId field has been removed and replaced with an optional failureReason field. Several required fields in ResultMetadata (patientFirstName, patientLastName, dob, labName) are now optional. The UserInfo interface now uses UserAddress instead of Address type. New CompendiumClient added for lab test search and conversion operations.
* The SDK now supports lab account management and order transaction tracking. New `LabAccountClient` provides team lab account retrieval with filtering capabilities. Added `OrderTransactionClient` for comprehensive transaction management including result access. Enhanced lab test creation with lab account and provider selection options, plus new filtering capabilities for order queries by transaction ID.
* New compendium service provides lab test search and conversion functionality for discovering and mapping lab tests across different providers. Samsung Health is now supported as a data source provider. Enhanced lab testing workflows with new order transaction management, parsing job tracking, and address access notes for delivery instructions.
* New order transaction management capabilities with status tracking and order grouping. Added lab account management types supporting delegated flows and billing configurations. Introduced lab report parsing job events for workflow tracking. Added support for Sonora Quest lab and Samsung Health provider. Enhanced appointment, order, and address types with additional optional fields for better data capture.
* The SDK now supports new functionality for compendium search, lab account management, and order transaction handling. New types include compendium search responses, lab account status tracking, order transaction management, and enhanced address objects with access notes. Additional enum types for US states, search modes, and result metadata have been added.
