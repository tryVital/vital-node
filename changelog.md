## 4.0.0 - 2026-03-31
* Several exported TypeScript types related to bulk operations have been removed: `LinkBulkExportRequestTeamId`, `LinkBulkImportRequestTeamId`, `LinkBulkPauseRequestTeamId`, `LinkBulkTriggerHistoricalPullRequestTeamId`, and `LinkListBulkOpsRequestTeamId`. These types were associated with deprecated teamId parameters that have been removed from the corresponding request interfaces. If you were importing these types directly, they are no longer available. The bulk operation request interfaces themselves remain available with simplified signatures.
* The lab report parser's `parserCreateJob` method now accepts an array of files instead of a single file, enabling batch processing of multiple lab reports in one request. Existing code calling this method must be updated to pass an array of files (e.g., `[createReadStream("path/to/file")]` instead of `createReadStream("path/to/file")`).
* The SDK now supports filtering lab test orders by transaction ID through the new `orderTransactionId` parameter in `getOrders()`. Added optional `clinicalNotes` field when creating orders and `allowStale` parameter for PSC appointment availability requests to allow cached data. Enhanced marker retrieval with lab-specific filtering via the new `labSlug` parameter.
* The SDK now includes enhanced insulin injection tracking with new optional fields for delivery mode, delivery form, and bolus purpose. Additional lab providers (Sonora Quest, CRL) and Samsung Health manual provider are now supported. Lab result metadata has been expanded with an optional gender field, and new order statuses for corrected results and lab processing blocks are available.
* New client capabilities added for compendium operations, lab account management, and order transaction tracking. The SDK now includes CompendiumClient for searching and converting lab test data, LabAccountClient for managing team lab accounts, and OrderTransactionClient for retrieving transaction details and results. Additional parameters have been added to existing lab test methods for enhanced filtering and appointment management.
* The SDK now supports insulin pump devices as a source type for health data across sleep, ECG, and menstrual cycle tracking. Added comprehensive lab test compendium search and conversion capabilities for finding and converting tests between different lab providers. Enhanced order tracking with transaction-based grouping, detailed status information, and clinical notes support. Sleep data now includes recovery/readiness scores for better wellness insights.
* New compendium search and lab test conversion endpoints are now available for discovering and converting lab tests between different providers. The SDK also includes enhanced insulin injection data with delivery mode, delivery form, and bolus purpose information, plus improved lab account management features with status tracking and delegated flow support.
* This release adds comprehensive lab testing enhancements including order transaction tracking, lab account management, and compendium search functionality. New provider support includes Samsung Health and Tandem Source for diabetes management. Enhanced data querying capabilities include insulin injection timeseries and derived readiness metrics. Patient address objects now support access notes for delivery instructions.
* The SDK now supports new query expression types for sleep readiness, awakenings tracking, and insulin injection timeseries. Added compendium search functionality for lab test matching and enhanced lab account management capabilities. Expanded address handling with new UserAddress type and access notes support.
