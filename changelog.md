## 4.0.0 - 2026-03-27
* The `insulin_injection` value has been removed from the `IntervalTimeseriesExprTimeseries` enum. Code that references this enum value will need to be updated to use alternative timeseries types or remove the dependency on insulin injection data.
* The `parserCreateJob` method in `LabReportClient` now accepts an array of files instead of a single file. Existing code should wrap single files in an array: replace `parserCreateJob(file, request)` with `parserCreateJob([file], request)`.
* New optional parameters added to Lab Tests API: `labSlug` for marker filtering, `orderTransactionId` for order searches, and `allowStale` for cached appointment availability data.
* The SDK now supports expanded insulin injection data with new optional fields for delivery mode, delivery form, and bolus purpose. Three new API clients are available: CompendiumClient, LabAccountClient, and OrderTransactionClient for enhanced laboratory and order management capabilities. Additional provider types and order status values have been added to support more health platforms and tracking scenarios.
* New compendium, lab account, and order transaction management capabilities are now available. The SDK includes three new client modules: CompendiumClient for lab test search and conversion, LabAccountClient for managing team lab accounts, and OrderTransactionClient for tracking transactions and retrieving results. Enhanced lab test workflows now support appointment booking, improved filtering options, and mobile SDK version tracking in manual connections.
* The SDK now supports insulin injection data tracking with new timeseries expressions for delivery mode, form, and bolus purpose. Address interfaces now include an optional accessNotes field for delivery instructions. New lab testing capabilities include Sonora Quest lab support, order transaction tracking, lab account management, and enhanced compendium search functionality for biomarker discovery.
* The SDK now supports compendium search and conversion functionality for mapping lab tests across different laboratory providers. New capabilities include searching the lab test compendium, converting between provider formats, enhanced insulin injection data with delivery modes and bolus purposes, lab account management, order transactions, and appointment booking with clinical notes.
* The SDK now supports order transaction grouping for lab tests, insulin injection timeseries data, and enhanced lab compendium search capabilities. New provider integrations include Tandem Source and Samsung Health, with expanded data fields for patient addresses and order management. Lab report parsing events are now available through webhooks with detailed status tracking.
* The SDK now supports enhanced lab data search and management capabilities with new types for compendium search responses, related candidates, and lab account management. Additional address management features are available with new UserAddress type and UsState enum, plus expanded query expression support for derived readiness and insulin injection data.
